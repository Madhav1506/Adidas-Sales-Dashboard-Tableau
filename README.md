
An interactive Tableau dashboard analyzing Adidas sales performance, operating profit, and units sold across regions, retailers, and product categories. Provides actionable business insights through data visualization and interactive filters.


## 📌 Project Overview

This project presents an interactive **Adidas Sales Analysis Dashboard** built using Tableau and Excel. It provides insights into sales performance, units sold, and operating profit across different regions, retailers, and product categories.

The dashboard helps users understand sales trends, compare business performance, and identify key areas contributing to overall revenue and profitability.

## 🎯 Key Features

- 📊 **Sales Performance Analysis** – Analyze total sales and overall business performance.
- 💰 **Operating Profit Analysis** – Evaluate profitability across different business segments.
- 👟 **Product Category Analysis** – Compare performance across Adidas product categories.
- 🌍 **Regional Analysis** – Explore sales performance across different geographical regions.
- 🏬 **Retailer Comparison** – Compare sales and profitability across retailers.
- 📦 **Units Sold Analysis** – Track product sales volume.
- 🎛️ **Interactive Filters** – Explore data using dashboard filters and selections.
- 📈 **Business Insights** – Identify high-performing categories, retailers, and regions.
